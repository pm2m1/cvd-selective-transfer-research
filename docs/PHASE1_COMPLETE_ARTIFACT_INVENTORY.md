## Source identity and evidence strength

The frozen result file has public SHA256 `b23106ccae093c0bcfcc63a2754d443a9b67f50ea65cbaafc04dbed003595bf3`, retained in the original supplement and [frozen bindings](phase1/frozen-public-bindings.json). Those bindings cover public source/artwork only, not confidential source-release fingerprints. New figure renderers read that existing JSON directly; they do not fit models, inspect scores or recompute bootstrap intervals.

Passing a synthetic test proves the exercised software behavior, not historical execution or clinical accuracy. A completed local report build proves typesetting, not publication permission. Report/source status and previously recorded test counts remain historical; current actual validation is recorded in PR #1 and the local final audit. The README and gallery deliberately expose these boundaries rather than presenting every local item as published.
