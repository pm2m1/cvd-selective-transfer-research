## The paired AP addition

The original seven-figure release lacked a direct visual display of the primary paired estimand. The concise academic copy already had an approved-aggregate contrast PDF. This update adds an SVG using the **same existing public JSON** for four contrasts: logical minus full fine-tuning, head-only, matched random and source five-view. It does not import the academic report or an unreviewed private plot. Reproduction instructions are in [reproducibility](phase1/reproducibility.md); numeric checks use the approved JSON rather than values transcribed from a screenshot.

The primary difference remains +0.001819 with interval [−0.024809,+0.032340]. The other contrasts are secondary. No displayed interval establishes superiority. No private test vectors, participant data, threshold cells, source-release fingerprints, report identifiers or execution evidence enter the new SVG.

## Deliberately withheld / unsupported assets

| Candidate | State | Reason |
|---|---|---|
| Empirical threshold confusion matrices | Restricted, not tracked | Exact cells/figures have not passed the separate public-disclosure gate |
| Private ten-draw threshold-response plot or screenshot | Restricted, not tracked | Means/SD on the same participants are not automatically safe aggregates; differencing and destination-specific disclosure review required |
| Expanded local-review threshold academic report | Restricted, not tracked | Contains unreleased supplementary results; filename recency/completeness is not publication permission |
| Actual B.Tech PDF/LaTeX | Staged locally only, not tracked | Separate authorship/identifier/form/institute/public-distribution approval is unresolved |
| ROC/PR or calibration curves inferred from scalars | Unsupported | AP/AUROC/Brier scalars cannot reconstruct authentic curves or score distributions |
| New HRS → ELSA performance plots | Not available | No validated real-data training/performance result is established |

The repository has **eight approved-public original-result/method SVGs plus one explicitly synthetic SVG** after this addition. Only seven of those original/public-method figures are used in the concise academic report: its architecture/cohort visuals correspond conceptually to repository artwork, five other PDFs correspond to the validation/test/parameter/mask/paired results. The audit timeline is an additional repository asset. Report assets remain outside Git while academic publication review is pending.
