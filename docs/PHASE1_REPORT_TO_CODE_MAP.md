## Interpretation of this map

The [public runner](../src/dmv_mat_cvd/experiments/runner.py) can evaluate invented target-test data after its fitting boundary; that is not permission or a command to reopen the original MHAS test. The original six cohort roles, ten paired clinical draws, source/target preprocessing and all 13 original fits are documented historically, while this release exposes generic mechanisms and approved summaries. Private cohort assignments, real preprocessors, clinical checkpoints, execution receipts and test score arrays are not supplied. Neither synthetic tests nor stored aggregate JSON can replace them.
