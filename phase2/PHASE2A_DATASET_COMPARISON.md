# Phase 2A dataset comparison — documentation screen, 26 October 2026

**Scope.** This is a documentation review, not an eligibility analysis. No HRS, ELSA, CHARLS or SHARE participant file was downloaded or inspected. None of their published whole-wave sizes is an eligible cardiovascular-event count. The closed HAALSI→MHAS test is excluded from every Phase-2 proposal.

## Feature tiers to test before choosing a model

1. **Common clinical/survey tier:** age, baseline sex, smoking, BP, BMI, and doctor-reported diabetes/antihypertensive treatment **only where their timing, routing and meaning are verified in both cohorts**. This is a proposal, not a claim that all eight fields are presently comparable or complete. Omit any unverified field symmetrically and version the schema.
2. **Lipid-extended tier:** the common tier plus total and HDL cholesterol only where cohort-specific assay, unit, collection date, consent and missingness permit a defensible common landmark. This narrower biomarker subcohort must be analyzed separately, with its own attrition/selection assessment.
3. **Information-extended tier (separate scientific question):** socioeconomic measures, glycaemic markers or other new predictors only if documented in *both* populations. A performance gain here cannot be attributed to the adaptation algorithm. Compare methods within the **same participant set and same tier**.

## Unresolved quantitative gate

No authorized Phase-2 extract or official cross-wave tabulation currently gives the count of **baseline heart-attack/stroke-free people with a valid common feature set, observed follow-up and a new report** in HRS or ELSA. Therefore eligible N, incident events, deaths and loss to follow-up are **unknown**. The HRS/ELSA pairing is a hypothesis for an independent experiment, not a feasible evaluation cohort yet. Acquire data through each official user account, verify licence conditions, create an aggregate-only exclusion/endpoint waterfall, and run a prespecified validation-precision calculation before any split or fitting.
