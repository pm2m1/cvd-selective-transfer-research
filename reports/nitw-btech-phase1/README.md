# Academic reports are reference-only

The author explicitly excludes all B.Tech PDFs, LaTeX projects, Overleaf ZIPs, bibliographies and academic submission documents from GitHub. This restriction applies regardless of whether their underlying figures or aggregates are approved. No report files are included. Research implementation and eligible outputs are in the [research archive](../../research/README.md), [results](../../results) and [figures](../../figures).

Earlier report references in preserved historical documentation describe local academic versions, not a plan to publish them. Do not add an academic report around the release guard. The current ignore/format checks reject PDF/TeX/STY/BIB/ZIP submission files.
