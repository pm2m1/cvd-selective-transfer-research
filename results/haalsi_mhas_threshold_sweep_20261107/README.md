# HAALSI → MHAS retained-score threshold supplement

Public code readiness: **READY_FOR_INDEPENDENT_THRESHOLD_SWEEP**. Actual private threshold comparisons: **NOT EXECUTED BY CODEX**.

This separate package calculates fixed operating points0.05,0.10,…,0.50 from the original retained frozen probabilities. It never retrains, loads checkpoints, invokes inference, transforms scores, changes historical results or searches for clinical inputs. The original metrics mathematics/test loader and independent-local runtime are copied byte-for-byte into `frozen_metrics.py` and `local_execution.py`.

The shortest path uses the completed0.50 calculation's **recorded provenance configuration**, not newly guessed NPZ paths or keys. The preparer creates only a fresh unresolved sweep configuration, referencing that metadata by SHA256. After independently applicable scope is established, a new purpose-specific interactive authorization and unused protected output are required. See `PRIVATE_OPERATOR_RUNBOOK.md`.

Every requested model/draw must reproduce the original per-draw and mean AP/AUROC/Brier at the existing1e−8 absolute/relative tolerances before reports are written. The original283 people,21 positives and262 negatives, ID ordering, prediction/ID fingerprints, registration/checkpoint inventory and shared-label matrix shape are enforced. Adapted methods have ten draws; source-only has its single original score vector. No ensemble or artificial2,830-person population is created.

The existing public metrics schema addresses six primary-budget methods: calibrated logical, head-only, full fine-tuning, matched random, source-only multiview and target logistic. Actual execution reuses the exact model inventory in the recorded metrics configuration; it neither silently drops requested models nor invents unavailable methods/metrics. With all six, five ten-draw methods plus one source vector give51 score vectors and510 fixed-grid confusion matrices. This is a count of planned calculations, not a new empirical finding. Other original13-method ranking results remain frozen; this supplement does not claim threshold results for models absent from the recorded configuration/reference inventory.

Output includes per-draw CSV/JSON, descriptive mean/SD/range/definedness summaries, separate integer-valued confusion SVGs for each model/draw/cutoff, summary SVG/PNG plots and a private Markdown supervisor report. Mean fractional counts are labeled descriptive and never drawn as one confusion matrix. All actual outputs remain protected pending disclosure review, including small cells and differences across thresholds.

Validation selection defaults to **ORIGINAL_VALIDATION_OPTIMAL_THRESHOLD_NOT_ESTABLISHED**. Authentic original validation scores may be supplied only with independently verified provenance, matching frozen checkpoints and disjoint171-person/13-positive membership. F1 selection uses validation alone, ties favor the highest threshold, and precedes test-score access. No cutoff is optimized on test labels. Even a supported validation-selected result remains supplementary/post-hoc on an already examined test, not fresh confirmatory evaluation.

Dependencies use the existing compatible environment; tested versions are in `requirements.txt`. No network or telemetry exists in the analysis. `--synthetic-demo` generates invented data internally and refuses external configuration/authorization. Tests use temporary invented fixtures only. The public ZIP contains source, cleared ranking references, templates and tests—not private predictions, records, receipts, checkpoints or completed threshold findings.
