# Focused independent scientific review of the existing diagnostic

Use only in the authorized private environment. Do not send counts, matrices, file paths, receipts, fingerprints or record examples to AI. This checklist creates no authorization and requests no new data operation. The reviewer needs both longitudinal survey methods and the relevant source-use scope; report authorship/competence accurately, without invented institutional endorsement.

1. **Bind existing evidence.** Verify the completed status diagnostic against its public release, frozen dictionary map, actual registered source descriptors and completion integrity evidence. Verify its scope covered H plus the relevant Core releases. Do not rerun it, reset any marker or reuse its authorization.
2. **Separate causes.** Read the existing wave-by-wave matrix and the first-conflict category. Distinguish explicit zero, missing, invalid participation and unmatched linkage; direct outcome evidence versus `askpx` fallback. Check all historical waves, not only W4/W6/W7/W9. Do not publish a data-conditioned category unless disclosure rules allow it.
3. **Audit lineage before precedence.** Establish exact key normalization, uniqueness, matching universe, source edition/revision and the harmonization derivation actually used. Local hashes establish integrity, not independently authenticated distributor provenance. A documented edition mismatch is not repaired by altering a checksum or suppressing the row.
4. **Verify joint semantics.** For every conflict family, compare the exact wave's outcome/proxy code labels and questionnaire route with H's response construction. A proxy-eligible household member need not have completed an interview. Explicit outcome codes, missing outcome codes, institutional codes, death codes and route flags must stay distinct. If public manuals cannot settle a joint combination, record unresolved interpretation; obtain appropriate authoritative clarification through the independent process if necessary.
5. **Classify the proposed action before seeing recovered event counts.** A: observability-only, acceptance unchanged. B: demonstrated implementation correction, with an exact specification violation and failing/passing synthetic fixture. C: scientific amendment, including any change to precedence, unknown-state handling, eligibility, quarantine/exclusion or interval reference. A plausible improvement is not proof of B.
6. **Trace consequences.** Check first-personal/lifetime evidence, last actual-interview reference, disease history, disputes, re-entry, death and closing follow-up. Do not silently remove a wave. No unknown MI/stroke may become zero; no prevalent report may become incident. Non-endpoint hypertension/diabetes are allowed. Preserve W6→9 primary and W4→7 comparator.
7. **Record a private determination.** State the evidence, unresolved families, selected A/B/C category, exact proposed semantics, affected windows, independent reviewer/author roles, prospective limitations and adoption status. If evidence is insufficient, stop at NO EXECUTION. Do not fabricate a signature or use a readiness boolean as proof of review.
8. **Release only what is justified.** Any B/C change needs a new reviewed public release, exact regression tests, source bindings and a fresh independent count purpose/output/authorization. Preserve the failed attempt forever. If only A is supported, counts remain blocked. Detailed judgments remain private until disclosure clearance.

Completion criterion: every observed conflict family has an evidence-supported treatment whose effects on history and follow-up are explicit. A single explained first conflict is insufficient to certify the entire source universe.
